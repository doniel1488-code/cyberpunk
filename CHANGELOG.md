# Changelog

## 0.1.0-alpha.9

- Rebuilt the cyberware interface into three tabs: implants, components and armor.
- Added inventory counts for all cybernetic parts and equipped-state/defense readouts for armor pieces.
- Expanded the fabrication catalog from five to twelve components.
- Added a second complete Assault Exoframe armor set with its own armor material and equipment textures.
- Added recipe-book advancement unlocks for all 29 mod recipes.
- Added new component and armor recipes and matching RU/EN localization.

## 0.1.0-alpha.8

- Added a dedicated cyberware management screen reachable from the vanilla player inventory.
- Added server-synchronized implant status, neural load, install and uninstall actions.
- Moved every mod item into a dedicated Cyberpunk creative tab instead of the vanilla Combat group.
- Fixed the cyberware armor equipment asset namespace so its humanoid and leggings layers resolve under the mod ID.
- Reworked cyberpsychosis into a target-lock and pursuit state with obstacle-aware steering, glowing target marks, close-range attacks and temporary control takeover.
- Added sustained neural interference HUD effects with red scanline tears and signal flashes.

## 0.1.0-alpha.7

- Removed the full-screen Sandevistan tint and kept status accents on the outer HUD frame.
- Fixed visual effect countdown to advance on client ticks instead of HUD render calls.
- Added implant status and removal commands.
- Added cybernetic crafting parts and a four-piece armor set.
- Added RU/EN item names, descriptions, recipes and equipment textures.
