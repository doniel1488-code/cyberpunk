# Cyberpunk — Fabric 1.21.8

Самостоятельный Minecraft-мод с кибернетическими имплантами для **Minecraft Java 1.21.8 + Fabric**.

## Импланты

| Имплант | Клавиша | Эффект |
|---|---:|---|
| Нейроускоритель | V | Speed III, Haste II и замедление мобов рядом |
| Оптический камуфляж | C | Невидимость, Speed II и визуальная маскировка |
| Берсерк | X | Strength III, Resistance II, Fire Resistance и Speed I |
| Сандевистан «Апогей» | B | Speed III, Haste II, замедление мобов в радиусе 64 блоков и голубые послеобразы игрока |
| Мантис-клинки | M | Strength III, Speed II и отравление при попадании |
| Руки гориллы | G | Strength IV, Resistance I, Haste II и сильное отбрасывание целей |
| Керензиков | K | Рывок по направлению взгляда, Speed IV, Jump Boost II и Resistance I |
| Подкожная броня | — | Пассивный Resistance I |
| Кровяной насос | P | Экстренное лечение, Regeneration II, Absorption и снятие Poison/Wither |

Одновременно можно держать активной только одну временную боевую систему. Кровяной насос используется отдельно. Подкожная броня работает пассивно.

## Установка и снятие

1. Возьми чип нужного импланта в руку и нажми **ПКМ** — чип будет установлен и израсходован.
2. Чтобы снять имплант, возьми в руку ещё один чип этого же типа и нажми **ПКМ** повторно. Имплант снимется, а чип останется в руке.
3. При снятии работающий эффект отключается сразу. Снятие не сбрасывает нейронагрузку.

В сообщении после установки мод показывает клавишу активации. Клавиши можно переназначить в **Настройки → Управление → Назначение клавиш**.

## Нейронагрузка и киберпсихоз

Использование и поддержание активных имплантов накапливает нейронагрузку. На 35% появляется предупреждение, на 65% — критическое состояние, на 100% начинается киберпсихоз.

Киберпсихоз длится 15 секунд: игрок получает боевые усиления, а киборг автоматически наносит удары всем видимым живым целям в радиусе 3,5 блока. Игрок сохраняет управление передвижением — мод больше не пытается постоянно направлять его прямо в ближайшую цель и не заставляет упираться в стены. Игроки в Creative и Spectator не атакуются. Остальные игроки, мобы и животные могут получить удар.

**Важно:** не набирай 100% нейронагрузки рядом с союзниками или в безопасной зоне.

## Кибернетические детали и броня

В alpha.7 добавлены детали для сборки оборудования:

- Киберсплав — базовая усиленная пластина для кибернетики.
- Сервопривод — механика для рук, ног и силовых систем.
- Нейропроцессор — управляющий чип для нервных имплантов.
- Синтетическое волокно — гибкий материал для защитных систем.
- Энергоячейка — компактный источник питания.

Из деталей создаются четыре части кибернетического экзокостюма: шлем, нагрудник, поножи и ботинки. Это настоящая носимая броня со своей прочностью, защитой и сопротивлением отбрасыванию. Полный комплект дополнительно даёт Resistance II и Speed I.

Детали, импланты и броня имеют рецепты верстака и отдельные игровые модели предметов. Киберброня использует отдельную текстуру экипировки.

## Требования

- Minecraft Java **1.21.8**
- Fabric Loader **0.16.0+**
- Fabric API **0.136.1+1.21.8**
- Java **21**

Для мультиплеера мод требуется на клиенте и сервере.

## Проверка и известные ограничения

GitHub Actions собирает и remap-ит JAR, проверяет наличие классов, текстур, моделей, рецептов, JSON и совпадение русской/английской локализации. Успешная сборка подтверждает компиляцию и упаковку, но **не заменяет запуск в Minecraft**.

- Послеобразы Сандевистана — голубые контурные копии модели игрока в местах предыдущего положения; это не отдельная шейдерная анимация.
- Замедление времени действует на мобов, а не на других игроков, предметы или снаряды.
- Модели самих имплантов на руках/теле игрока и хирургическая анимация риппердока пока не реализованы.
- Нейронагрузка и перезарядки хранятся в памяти сервера и сбрасываются после перезапуска.

## Сборка

JDK 21 и Gradle 8.14.3:

```bash
gradle --no-daemon clean build
```

JAR: `build/libs/cyberpunk-fabric-0.1.0-alpha.7.jar`.
