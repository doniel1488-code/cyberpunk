# Cyberpunk — Fabric 1.21.8

Самостоятельный Minecraft-мод с кибернетическими имплантами под **Minecraft Java 1.21.8 + Fabric**.

## Комплект имплантов alpha.6

| Имплант | Клавиша | Тип | Что делает |
|---|---:|---|---|
| Нейроускоритель | V | Активный | Speed III, Haste II, электрический след и замедление мобов рядом |
| Оптический камуфляж | C | Активный | Невидимость, Speed II и портальное мерцание |
| Берсерк | X | Активный | Strength III, Resistance II, Fire Resistance и Speed I |
| Сандевистан «Апогей» | B | Активный | Speed III, Haste II, замедление мобов в радиусе 64 блоков и модельные послеобразы |
| Мантис-клинки | M | Активный | Strength III, Speed II; удары накладывают короткое отравление и оставляют зелёные следы клинков |
| Руки гориллы | G | Активный | Strength IV, Resistance I, Haste II; попадания отбрасывают цель сильным ударом |
| Керензиков | K | Активный | Рывок в направлении взгляда, Speed IV, Jump Boost II, Resistance I и краткое замедление мобов в радиусе 12 блоков |
| Подкожная броня | — | Пассивный | Постоянно даёт Resistance I, пока имплант установлен; при получении урона показывает электрический отклик |
| Кровяной насос | P | Экстренный | Мгновенно восстанавливает до 4 сердец, даёт Regeneration II и 2 дополнительных сердца поглощения; снимает Poison и Wither |

Установка чипа: возьми предмет в руку и нажми ПКМ. Чип расходуется, а установленный имплант закрепляется в тегах игрока. Подкожная броня начинает работать автоматически. Кровяной насос — разовая активация с перезарядкой 45 секунд; остальные активные системы работают ограниченное время и имеют собственные cooldown.

## Киберпсихоз

Нейронагрузка растёт при активации и работе активных имплантов. На 35% идёт предупреждение, на 65% — критическая стадия, а на 100% начинается 15-секундная неконтролируемая ярость: киборг получает усиления, выбирает ближайшую живую цель в радиусе 24 блоков и преследует её, атакуя мобов и обычных игроков. Creative и Spectator исключены.

## Требования

- Minecraft Java **1.21.8**
- Fabric Loader **0.16.0+**
- Fabric API **0.136.1+1.21.8**
- Java **21**

Для мультиплеера мод нужен на клиенте и сервере. Клавиши можно переназначить в **Настройки → Управление → Назначение клавиш**.

## Проверка

GitHub Actions собирает и remap-ит JAR, проверяет классы послеобразов и Mixin, новые предметы, текстуры, модели, рецепты, валидность JSON и совпадение русских/английских ключей. Успешный CI подтверждает сборку и упаковку, но не заменяет игровой тест.

### Ограничения

- Модели имплантов на теле игрока и анимации хирургической установки ещё не реализованы.
- Керензиков замедляет мобов, но не других игроков, предметы и снаряды.
- Подкожная броня использует Resistance I; отдельная 3D-модель пластины под кожей пока не отображается.
- Руки гориллы используют усиленные обычные удары и импульс отбрасывания, а не отдельную модель рук.
- Киберпсихоз использует простое преследование цели; сложное обхождение стен и навигация пока ограничены.
- Перезарядки и нейронагрузка находятся в памяти сервера и сбрасываются после рестарта.

## Сборка

JDK 21 и Gradle 8.14.3:

```bash
gradle --no-daemon clean build
```

JAR: `build/libs/cyberpunk-fabric-0.1.0-alpha.6.jar`.
