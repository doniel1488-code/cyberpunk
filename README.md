# Cyberpunk — Fabric 1.21.8

Неофициальный Minecraft-мод в эстетике киберпанка. Цель проекта — собрать самостоятельную систему кибернетических имплантов, боевых модулей и сетевых способностей под **Minecraft Java 1.21.8 + Fabric**.

## Что уже есть в alpha.1

- Три импланта с собственными 16×16 иконками и рецептами: нейроускоритель, оптический камуфляж и модуль «Берсерк».
- Установка импланта: возьми его в руку и нажми ПКМ. Чип расходуется, а установленный модуль сохраняется в тегах игрока.
- Серверная обработка способностей и проверка установленного импланта перед активацией.
- **V** — ускорение игрока и замедление ближайших мобов в радиусе 14 блоков.
- **C** — невидимость и повышенная скорость.
- **X** — сила и сопротивление урону.
- У способностей есть длительность и перезарядка. Частое использование накапливает нейронагрузку; при перегрузке появляются негативные эффекты киберпсихоза.
- Русский и английский языки интерфейса и названий клавиш.

Планируемые системы:
- **Neural Accelerator** — кратковременное ускорение владельца и замедление ближайших мобов.
- **Optical Camo** — временная маскировка.
- **Berserk** — боевой режим с усилением и сопротивлением урону.
- **Cyberpsychosis** — нагрузка от частого использования имплантов.
- **Mantis Arms**, **Reinforced Tendons**, **Cyberdeck** и риппердок — последующие этапы.

## Сборка

Требуется JDK 21 и Gradle 8.14.3.

```bash
gradle --no-daemon clean build
```

Готовый мод: `build/libs/cyberpunk-fabric-0.1.0-alpha.1.jar`.

## Требования

- Minecraft Java 1.21.8
- Fabric Loader 0.16.0 или новее
- Fabric API 0.136.1+1.21.8
- Java 21

## Установка

1. Установи Fabric Loader для Minecraft 1.21.8.
2. Установи Fabric API для 1.21.8.
3. Скопируй JAR в папку `.minecraft/mods`.
4. Для мультиплеера установи мод на сервер и на клиент. Возможности рассчитываются на сервере; клиент без мода не сможет активировать импланты.

## Клавиши

| Клавиша | Имплант |
|---|---|
| `V` | Нейроускоритель |
| `C` | Оптический камуфляж |
| `X` | «Берсерк» |

Клавиши можно переназначить в **Настройки → Управление → Назначение клавиш**.

## Рецепты

- Нейроускоритель: незеритовая звезда, аметист, эхо-осколок и редстоун.
- Оптический камуфляж: стекло, аметист, жемчуг Края и редстоун.
- Модуль «Берсерк»: незеритовый лом, блоки редстоуна, порошок ифрита и золото.

## Проверка

GitHub Actions собирает и remap-ит JAR, затем проверяет наличие локализаций, текстур и рецептов внутри архива. Это проверка сборки, а не подтверждение игрового тестирования. На текущем этапе ещё предстоит проверить установку имплантов, эффекты, сетевую синхронизацию и баланс в реальном клиенте/на сервере 1.21.8.
