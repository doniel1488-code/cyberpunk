# Cyberpunk — Fabric 1.21.8

Неофициальный Minecraft-мод в эстетике киберпанка. Самостоятельная реализация под **Minecraft Java 1.21.8 + Fabric**.

## Что нового в alpha.5

### Сандевистан — B
- Сервер отправляет состояние Сандевистана ближайшим игрокам, поэтому след виден не только владельцу, но и наблюдателям с модом рядом.
- Клиент запоминает прошлые координаты и повороты игрока.
- Во время способности отрисовываются до семи неоновых контурных двойников той же модели игрока в прошлых точках движения — с актуальными скином и экипировкой.
- После выключения или окончания способности след плавно исчезает.
- Дополнительно остаются Speed III, Haste II, электрический след и замедление мобов в радиусе 64 блоков.

Это модельные послеобразы, а не облако частиц. Сейчас они выглядят как светящиеся контуры модели; полноценная полупрозрачная постобработка и хроматические шейдеры пока не используются.

### Киберпсихоз — режим ярости
- При 100% нейронагрузки активная способность прерывается, начинается 15-секундный режим неконтролируемой ярости.
- После короткого приступа дезориентации киборг получает Strength IV, Speed III, Resistance II, Haste II и Fire Resistance.
- Сервер выбирает ближайшую живую атакуемую цель в радиусе 24 блоков, разворачивает к ней игрока, преследует и атакует.
- После смерти или потери цели выбирается следующая. Ярость может атаковать мобов, животных, жителей и обычных игроков; игроки в Creative и Spectator исключены.
- При ударах появляются частицы урона и критического попадания, воспроизводится боевой звук. По окончании режима контроль возвращается, нейронагрузка остаётся на 30%.

### Остальные импланты
- **V — Нейроускоритель:** Speed III, Haste II, замедление ближайших мобов, электрический след.
- **C — Оптический камуфляж:** невидимость, Speed II, портальные мерцания.
- **X — Берсерк:** Strength III, Resistance II, Fire Resistance и Speed I.
- **B — Сандевистан:** Speed III, Haste II, замедление мобов и модельные послеобразы.

## Нейронагрузка
Нагрузка растёт при активации и во время работы способности. Более мощные системы нагружают нейросеть быстрее. В простое нагрузка постепенно снижается. На 35% появляется предупреждение, на 65% — критическая стадия, на 100% — киберпсихоз с неконтролируемой яростью.

## Установка
- Minecraft Java **1.21.8**
- Fabric Loader **0.16.0+**
- Fabric API **0.136.1+1.21.8**
- Java **21**

Положи JAR в `.minecraft/mods`. Для мультиплеера мод нужен на клиенте и сервере. Клавиши: V / C / X / B; их можно переназначить в настройках управления.

## Проверка и ограничения
GitHub Actions собирает и remap-ит JAR, проверяет классы afterimage/payload, mixin, JSON и ключи локализаций. Успешная сборка доказывает компиляцию и упаковку, но не заменяет игровой тест.

- Afterimages — неоновые контуры модели, а не полноценные полупрозрачные копии с шейдером.
- Ярость двигает игрока напрямую к выбранной цели; сложный обход стен и навигация по лестницам пока не реализованы.
- Ярость атакует любых обычных игроков и существ рядом, кроме Creative/Spectator. Не запускай её в безопасных или дружеских зонах сервера.
- Замедление Сандевистана касается мобов, а не других игроков, предметов или снарядов.
- Активность, перезарядки и нейронагрузка пока хранятся в памяти сервера и сбрасываются после рестарта.
