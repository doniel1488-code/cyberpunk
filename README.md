# Cyberpunk — Fabric 1.21.8

Неофициальный Minecraft-мод в эстетике киберпанка. Самостоятельная реализация под **Minecraft Java 1.21.8 + Fabric**.

> Код, текстуры и другие ассеты проектов с All Rights Reserved не копируются. Используются собственные реализации и оригинальные ресурсы.

## Что есть в alpha.4

Четыре доступных импланта, у каждого отдельные звук, всплеск частиц, цветная экранная вспышка при активации и периодические визуальные импульсы во время работы.

| Имплант | Управление | Эффект | Длительность / перезарядка |
|---|---:|---|---:|
| Нейроускоритель | V | Speed III, Haste II; замедляет ближайших мобов в радиусе 14 блоков; электрический след и облака за игроком | 9 / 18 секунд |
| Оптический камуфляж | C | Невидимость, Speed II, мерцающие портальные частицы | 8 / 24 секунды |
| Берсерк | X | Strength III, Resistance II, Fire Resistance и Speed I; огонь и критические частицы вокруг игрока | 7 / 25 секунд |
| Сандевистан «Апогей» | B | Speed III, Haste II; мобы в радиусе 64 блоков выполняют один полный тик из семи; электрический след | 9 / 15 секунд |

Сандевистан замедляет именно мобов. Другие игроки, предметы и снаряды этим Mixin не затрагиваются; это не глобальное изменение скорости времени Minecraft.

## Нейронагрузка и киберпсихоз

Нагрузка растёт при активации и во время работы импланта, причём разные системы нагружают нейросеть по-разному. Вне активных способностей она постепенно снижается.

- **35% — предупреждение:** звуковой сигнал и светлый экранный импульс.
- **65% — критическая стадия:** тошнота, слабость, кратковременное замедление и более сильный экранный сигнал.
- **100% — киберпсихоз:** активная способность прерывается, на 15 секунд блокируется активация киберсистем. Игрок получает краткую слепоту, тошноту, слабость и замедление; экран получает красные цифровые помехи, слышен сигнал перегрузки.
- После срыва нагрузка сбрасывается до 30% и снова постепенно восстанавливается.

Во время использования способности частицы и экранные импульсы продолжают показывать её состояние, а не только момент нажатия клавиши.

## Установка имплантов

1. Получи нужный чип по рецепту.
2. Возьми его в руку и нажми ПКМ — чип устанавливается и расходуется.
3. Используй назначенную клавишу для активации.
4. Клавиши можно переназначить в **Настройки → Управление → Назначение клавиш**.

Установленные импланты сохраняются в тегах игрока. Активные эффекты, перезарядки и нейронагрузка пока хранятся в памяти сервера и сбрасываются после перезапуска.

## Требования

- Minecraft Java Edition **1.21.8**
- Fabric Loader **0.16.0 или новее**
- Fabric API **0.136.1+1.21.8**
- Java **21**

Для мультиплеера мод должен быть установлен и на клиенте, и на сервере.

## Сборка

Требуются JDK 21 и Gradle 8.14.3.

```bash
gradle --no-daemon clean build
```

Готовый JAR: `build/libs/cyberpunk-fabric-0.1.0-alpha.4.jar`.

GitHub Actions собирает и remap-ит JAR, проверяет наличие визуальных классов и ресурсов, а также валидирует JSON и совпадение ключей русской и английской локализаций. Это подтверждает успешную сборку, но не заменяет тестирование в реальном клиенте и на выделенном сервере.
